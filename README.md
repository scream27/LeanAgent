# LeanAgent — Lean Refactor Arena

우리 팀의 Lean 증명 개선 프로젝트입니다.
명제는 유지하면서 증명을 짧게 만들고 검증 비용을 줄입니다.

## 할 일

1. 문제와 실행 환경을 준비합니다.
2. 에이전트로 증명 후보를 만듭니다.
3. Lean으로 후보를 검증합니다.
4. 제출할 후보를 선택하고 결과를 기록합니다.
5. 대시보드에서 결과를 확인합니다.

## 폴더

- `benchmarks/`: 대회 문제 정보
- `data/`: 문제 데이터와 목록
- `experiments/`: 실험 코드와 설정
- `runs/`: 실행 결과
- `scripts/`: 데이터 준비 도구
- `tests/`: 코드 검사
- `dashboard/`: 선택 후보와 검증 결과를 보여주는 화면
- `docs/`: 설계와 사용법

후보 저장 구조가 정해지면 15문제의 결과를 대시보드에 연결합니다.
[대시보드 사용법](dashboard/README.md) · [데이터 사용법](data/README.md)
